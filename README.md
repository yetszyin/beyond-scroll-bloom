# Beyond Scroll Bloom

建立手機優先、全站繁體中文（香港用語）的「智醒樂活 Beyond Scroll」互動 App Demo，不要 PPT 或簡報。視覺參考用戶提供的圖片：奶油白、森林綠、鼠尾草綠、暖橙、圓角卡片、溫暖人物插畫、留白充足、長者友善大字與大按鈕。四個底部導航：首頁、挑戰、活動、我的。首頁有問候、今日數碼生活時間（標示示範數據，不可假稱真實監測）、今日挑戰／線下活動入口、每日小任務及小紅花。挑戰頁有護眼操、椅上伸展、散步任務打卡和一個可操作的簡單益智遊戲。活動頁有健康、藝術文化、音樂、園藝、義工等主題；每個主題點入只顯示一個精選活動，其餘位置顯示「🔒 敬請期待」。健康主題展示香港房協長者安居資源中心官方活動：2026年11月25日「食出肌肉－認識肌少症與長者營養」講座。簡介：認識肌少症與長者營養，了解日常飲食與肌肉健康。來源連結 https://erc.hkhs.com/event/page/calendar?page=1 。不得杜撰地點、收費、名額、截止日期；未知資訊寫「詳情請向主辦機構查詢」。清楚註明「此為產品示範，活動資料及名額請以主辦機構最新公布為準；示範報名不會實際提交至主辦機構。」活動報名、邀請好友、結伴同行加入／發起活動均用前端模擬互動並明確提示為示範，不可聲稱真實提交。活動頁另有一個示範用戶結伴同行貼文。我的頁有陳伯伯、積分、小紅花、任務紀錄、好友。所有使用者可見文字全部繁體中文，品牌英文除外；無需登入、資料庫、API。做出完整可點擊流程、手機響應式 UI，目標是發布成可分享公開 Demo 網址。
